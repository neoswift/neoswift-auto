NEOSWIFT AUTO WEBSITE V2

READY TO USE:
1. Open index.html to preview.
2. Upload index.html and infiniti-g37x-listing.png to the root of a GitHub repository.
3. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.

Included:
- Mobile responsive design
- Current Infiniti listing
- Click-to-enlarge listing image
- Call/Text button
- Email button
- Sell Your Car form (uses visitor's email app, so no server/database is needed)
- About/Why Us section
- Contact section

Before publishing, verify all public vehicle and contact information.
